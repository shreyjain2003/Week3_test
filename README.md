# Week 3 – C# OOPS Assignments

This repository contains two C# console-based applications developed as part of the Week 3 training assignment.  
The focus of this week was on applying **Object-Oriented Programming (OOPS)** principles, **generic collections**, and **delegates** in real-world scenarios.

---

## 📦 Projects Included

### 1️⃣ PayrollApp
A payroll and salary processing system that:
- Uses inheritance and polymorphism for employee types
- Calculates salaries without conditional logic
- Uses delegates to notify HR and Finance departments
- Generates a complete payroll summary

📂 See: `PayrollApp/README.md` for full details

---

### 2️⃣ OrderProcessingApp
An online order processing system that:
- Models products, customers, and orders
- Enforces order status workflows with validation
- Records full order status history
- Uses multicast delegates for customer and logistics notifications

📂 See: `OrderProcessingApp/README.md` for full details

---

## 🧠 Key Concepts Demonstrated

- Encapsulation, Inheritance, Polymorphism
- Composition
- Generic Collections (`List<T>`, `Dictionary<TKey,TValue>`)
- Delegates (Multicast)
- Exception Handling
- Clean separation of responsibilities
